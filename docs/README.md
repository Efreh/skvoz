# Документация SKVOZ

SKVOZ объединяет ядро двунаправленных байтовых потоков, клиенты и вспомогательные
компоненты. Сейчас реализованы универсальный Core, менеджер множества участников,
опциональная среда выполнения NATS, отдельный демон с IPC, серверный коннектор
и минимальный ретранслятор TCP; клиентских приложений пока нет.
