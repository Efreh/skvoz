# Документация SKVOZ

SKVOZ объединяет ядро двунаправленных байтовых потоков, клиенты и вспомогательные
компоненты. Сейчас реализованы универсальный Core, менеджер множества участников,
опциональная среда выполнения NATS, отдельный демон с IPC, общий TCP/IP runtime, серверный коннектор,
нативный клиент Ubuntu и минимальный ретранслятор TCP.
