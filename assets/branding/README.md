# Знак SKVOZ

Основной знак — две фактурные графитовые плиты с открытым зелёным разрывом.
Используйте [skvoz.png](skvoz.png), прозрачный PNG 1024×1024, или готовую
копию [256×256](skvoz-256.png). Сохраняйте исходные цвета, пропорции и прозрачность;
выбирайте размер исходника не меньше размера отображения с учётом плотности экрана.

[Компактный цветной знак](skvoz-compact.png) предназначен только для 16–24 px.
Начиная с 32 px используется основной знак. Одноцветных вариантов логотипа нет.
Знак обозначает приложение или проект; пиктограммы действий и состояний
сохраняют своё значение.

Android хранит цветные ресурсы в `clients/android/app/src/main/res`:
adaptive launcher имеет графитовый фон и пять плотностей foreground 108 dp,
с основными элементами в центральной безопасной зоне 66 dp. В шапке и крупной
иконке уведомления используется основной PNG без tint. Обязательный малый
системный индикатор уведомления остаётся отдельной функциональной пиктограммой.
Android может самостоятельно изменять отображение иконок при включённой
системной теме.

Ubuntu хранит размеры 16, 24, 32, 48, 64, 96, 128, 256 и 512 px в
`clients/ubuntu/assets/icons`. Сборка deb устанавливает их в соответствующие
каталоги `hicolor` под именем `org.skvoz.Client`. Launcher и панель используют
это имя, а знак в окне встроен в бинарный файл. Состояние соединения отображают
подписи, отдельный индикатор в окне и меню панели.
